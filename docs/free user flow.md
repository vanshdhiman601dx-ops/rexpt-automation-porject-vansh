Rexpt Web Application Automation Planning Document
Free User Flow Automation
Objective

This document defines the complete automation execution flow for a Free User of the Rexpt Web Application using Playwright with JavaScript. The automation validates the complete user journey starting from Signup until Dashboard verification, ensuring that all data generated during onboarding is stored and later verified across the application.

Assertion Strategy

Every validation must compare the actual application value with the expected value (either a fixed expected value or data stored in free-user-flow.json).

If any comparison fails:

Trigger an assertion.
Mark the current validation as Failed.
Capture the failure in the automation report with the expected value, actual value, and validation name.
